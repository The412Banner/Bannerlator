ALZip EGG / AZO support (in-app, no native engine)
==================================================

BFE unpacks ALZip's .egg archives with its own Kotlin code (unpack/EggArchive.kt and
unpack/AzoDecoder.kt, part of BFE, GPL-3.0). It was written from ESTsoft's published "EGG Format
Specification, Version 1.0"; ESTsoft's own EGG decompression module is not used. Credits:

Compression libraries used for EGG blocks: java.util.zip (Deflate), Apache Commons Compress
(BZip2) and XZ for Java (LZMA) — see THIRD_PARTY_LIBRARIES.txt.

Not supported: encrypted EGG archives (ZIP 2.0 / AES / LEA) — BFE says so before starting.
