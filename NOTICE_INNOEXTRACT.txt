innoextract engine bundled as libinnoextract.so (+ dependency libraries)
========================================================================

Purpose
-------
libinnoextract.so is the engine for STANDARD InnoSetup / GOG installers (setup_*.exe).
7-Zip only sees these as a Windows PE and cannot decompress the Inno-packed game data;
innoextract reads the Inno archive format directly. Device-verified: extracts a real GOG
installer (Stronghold Crusader HD, Inno 5.6.2) — 4095 files / 868 MB — from inside the
app's exec sandbox.

Provenance & Android-seccomp requirement
-----------------------------------------
These are BIONIC (Android) builds from the Termux aarch64 packages, produced by the same
NDK r29 clang toolchain used elsewhere in this app. A bionic build is REQUIRED: a
generic-Linux innoextract inherits the app's seccomp-bpf filter and SIGSYS-dies (exit 159,
the same lesson as the 7-Zip binary). Bionic builds integrate with Android's seccomp — the
same reason Termux (itself an app) runs them.

Packaging fix-ups (so Android can load them from the native-lib dir)
-------------------------------------------------------------------
Android only packages/loads native libs named `lib*.so` (no versioned suffixes). Three
dependencies had versioned SONAMEs, fixed with patchelf:
  liblzma.so.5   -> liblzma.so
  libz.so.1      -> libz.so
  libbz2.so.1.0  -> libbz2.so
For each: `patchelf --set-soname <new>` on the library, and `patchelf --replace-needed
<old> <new>` on every consumer (libinnoextract.so, libboost_iostreams.so). Termux RUNPATHs
were removed; at runtime the binary is exec'd from applicationInfo.nativeLibraryDir with
LD_LIBRARY_PATH set to that dir so the loader finds the bundled libraries. No code was
modified — only ELF metadata (SONAME/NEEDED/RUNPATH).
