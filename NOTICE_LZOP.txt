lzop + LZO bundled as liblzop.so
================================

Purpose
-------
Decompresses lzop files (.lzo, .tzo, .tar.lzo) for BFE's Unpack screen (ExtraFormats engine),
fed on stdin; a resulting .tar is then unpacked by the bundled 7-Zip.

Both sources are unmodified. The one build-time change: lzop's own global function sysinfo()
(help.c) is renamed with -Dsysinfo=lzop_sysinfo because it collides with the sysinfo() syscall
wrapper in bionic's static libc.a. BFE is GPL-3.0, which is compatible with GPL-2.0-or-later.

Build
-----
.github/workflows/build-extract-tools.yml (Android NDK r29, aarch64-linux-android26): LZO built
static (--disable-shared), then lzop configured against it with LDFLAGS=-static. The complete
corresponding source is the two tarballs above plus that recipe.
