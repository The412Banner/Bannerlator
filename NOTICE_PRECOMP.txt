precomp bundled as libprecomp044.so … libprecomp048.so
=======================================================

Purpose
-------
Some FreeArc archives run their data through precomp before compressing it. precomp expands the
zlib/deflate, JPG, MP3, GIF, bzip2 and lzma streams inside a file so the outer compressor can do
better, and restores the original bytes exactly ("precomp -r"). A precomp file (PCF) can only be
restored by the precomp version that wrote it, so BFE ships one binary per open-source release.
libbfeext.so (part of BFE) reads the version from the PCF header and runs the matching binary.

Build
-----
.github/workflows/build-repack-tools.yml: sources pinned by SHA-256, cross-compiled with the Android
NDK r29 for aarch64-linux-android26, linked fully static. Recipe: native/precomp/build.sh (reads the
source lists from each release's own Makefile; v0.4.8 uses its CMakeLists). No functional changes;
the build only adds compiler flags so the 2016-2021 C code compiles with current clang and bionic.
