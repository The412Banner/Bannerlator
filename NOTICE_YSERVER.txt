yserver (X11 server) bundled as libyserver.so
=============================================

Purpose
-------
The X server Bannerlator runs instead of its Java X server when a game sets BANNER_YSERVER=1: Wine's
windows are shown through Bannerlator's Wayland compositor. Off unless that variable is set.
