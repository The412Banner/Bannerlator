Reproduction steps1. arm64ec container: Proton-11.0-2-arm64ec (v14), Wrapper + bcn_layer (System, Vulkan 1.3), DXVK 2.7.1.1-sdk36-arm64ec, FEXCore 2609-unix. 2. Launch Hospital Seduction.exe, play through Night 1. 3. Sleep in the bed (HeroSleepBed) to start Night 2. 4. Screen goes black, the game process RSS climbs ~250 MB/s from ~1 GB to ~4.6 GB within ~15 s, then Android's low-memory killer kills it (back to home). 100% reproducible, always at the Night 1 -> Night 2 transition.
Already triedKEY FINDING 1 - DXVK never loads in this container. Unity Player.log (via -logFile) always reports WineD3D's fallback card: Direct3D: Version: Direct3D 11.0 [level 10.1] Renderer: NVIDIA GeForce 8800 GTX (ID=0x191), VRAM: 768 MB even though DXVK is selected on both the container and the shortcut and Direct3D = Native (Windows). With DXVK_LOG_LEVEL=info no DXVK log files are written. DXVK_CONFIG=d3d11.maxFeatureLevel=11_0 has no effect (DXVK not loaded). KEY FINDING 2 - right before the crash Unity rejects the Night 2 textures because of the FL 10.1 limit: Texture with ID 764 and with size 15280x1240 was too large for graphics device maximum supported texture size (8192x8192). Falling back to a dummy texture. (5 textures: 13752x1052, 13752x1240 x3, 15280x1240), then "UnloadTime: ~450 ms", then the log goes silent while RAM explodes. The GPU itself reports maxImageDimension2D = 16384. Same crash at the same point in GameHub 6.3.1 and BannerHub 3.8.1 (DXVK does load there), so the texture limit may not be the only factor. Tried, no change to the crash: - BCN_TRANSCODE_TO_ASTC=1 (baseline RAM dropped ~1.5 GB -> ~1 GB, spike still happens) - Codecs GStreamer and FFmpeg (winedmo) - game has six 1080p H.264 cutscenes - WINEDLLOVERRIDES=mfplat=d (Media Foundation off) - same spike, so video is ruled out - DXVK 1.11.1-sarek and 2.7.1.1-sdk36-arm64ec, Proton 10.0 and 11.0-2 arm64ec, 960x540 and 1280x720 - Phantom process killer disabled, battery optimization off, background apps closed Questions: 1) Why does DXVK not load (falls back to WineD3D) in an arm64ec container with Wrapper + bcn_layer on Mali-G57? 2) Any way to expose D3D11 feature level 11_0 (16384 textures) to a game on this GPU?
