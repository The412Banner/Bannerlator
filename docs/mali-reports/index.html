How to grab a log first (do this before submitting)
  1. Open Bannerlator → Settings.
  2. In the Logs section turn on Enable Wine Debug and Enable Box64 Logs.
  3. Set the log location dropdown to Download (saves to /sdcard/Download/bannerlator).
  4. Apply, then launch the game and reproduce the problem.
  5. Come back here and attach the log file(s) from that folder below.
