# Bannerlator 3.2.1

Run Windows apps and games on Android — no PC and no root required.

<p align="center"><img src="https://img.shields.io/badge/release-3.2.1-ff3d8b?style=for-the-badge" alt="3.2.1" />&nbsp;<img src="https://img.shields.io/badge/update-app--side%20%C2%B7%20no%20ImageFS%20reinstall-2dd4bf?style=for-the-badge" alt="app-side update" />&nbsp;<img src="https://img.shields.io/badge/new-network%20drives-22c55e?style=for-the-badge" alt="Network drives" />&nbsp;<img src="https://img.shields.io/badge/NAS%20streaming-experimental%20%C2%B7%20work%20in%20progress-f97316?style=for-the-badge" alt="NAS streaming: experimental, work in progress" />&nbsp;<img src="https://img.shields.io/badge/Lab-equal%20of%20Classic-22c55e?style=for-the-badge" alt="Lab is an equal of Classic" /></p>

**3.2.1 is everything since 3.2.0: network drives in the file manager, adding games from a network drive by copying them, Lab made a full equal of Classic, a choice of Lab's start page, device details, DroidDeck drivers, MGamer404's XMB art pickers, Wayland desktop fixes and store fixes.** It also brings, as an **experimental work in progress**, playing games straight from network (NAS) storage without copying them first.

- **Network drives:** a Network section in the file manager finds the shared drives on your home network; add SMB, SFTP, WebDAV or FTP drives, browse them and copy both ways.
- **Add to Games by copying:** copy a game folder from a drive to the device and add it to Games in one step; Bannerlator picks the game's program (not its launcher), and you can choose another.
- **🧪 Stream from network storage (experimental, work in progress):** start a game from a NAS without copying it first; its files come over as the game reads them. Expect rough edges.
- **Lab:** every Classic option now has a Lab page, a choice of start page (Home, Library or Containers), device details, and a thin outline round each Library card.
- **XMB** (by **MGamer404**): pick a game's wide cover and background, and a Home that follows the Interface scale.

> ✅ **Nothing to set up.** Update the app; containers and games keep everything.

> ⬇️ **Small update.** On 3.2.0 the in-app updater downloads about **18 MB** instead of the whole app (about 603 MB). Older versions, first installs and this page give the full APK.

> 🧪 **Streaming games from network (NAS) storage is experimental and still a work in progress.** It is marked "(test)" in the app, it works with some games and not yet with others, and it will change in coming releases. Copying a game to the device stays the reliable way to play it. Please report what misbehaves, with the game's logs.

> ✅ **Device-tested:** everything new in 3.2.1 was tried on a device (the Pocket FIT) and works. Streaming from network storage stays experimental (above). Please report what misbehaves on yours, with a screenshot.

# What's New — everything since 3.2.0

## 🔁 What changes when you update

- **Lab › Settings › Open the app on** now offers **Home**, **Library** and **Containers**, and opens that page. If you had chosen **Games**, Lab now opens on **Library** (it used to open Home); never set, it opens Home as before. Classic and the Deck / XMB look keep their own choices.
- **Uninstall on a store's own page** (Steam's Library tab, the Xbox, Epic and GOG game pages, Amazon's list and game page) now removes the game's shortcuts too, as Downloads already did. Shortcuts whose game folder is kept stay.
- **The ✕ in the store menu** (tap the store name at the top left) leaves the store.
- **A sound pack without its own start-up sound** plays none, instead of Steam Big Picture's.
- **XMB:** the Home's covers and the opened game view follow the Interface scale; the tab labels no longer change with Font size.

## 🗄️ Network drives in the file manager

- **File manager › Home › Network:** the first time, Bannerlator downloads the **rclone** engine once (about 15 MB, the same build Banners File Explorer uses, checked against a pinned SHA-256); it is not inside the APK.
- **Finds the drives on your network:** the shared (SMB) drives on your home network are listed by themselves, marked open or "needs login". **Search again** looks once more.
- **Add a drive:** SMB, SFTP, WebDAV or FTP, with an address, port and login; logins are kept encrypted on the device, and a wrong port or a server of another kind gets a plain message.
- **Browse and manage:** open folders on a drive, copy and move between the drive and the device both ways, rename, delete and make new folders, with the same menus as the rest of the file manager.

## ➕ Add to Games from a drive

- **Add to Games** on a game folder or an .exe on a drive: **Copy to** Internal storage or the SD card (their Winlator/Games folder) or a folder you choose; the last place is remembered and shown first.
- **Finds the game folder** when you start on an .exe several folders down (build folders like Binaries/Win64 are skipped).
- **Game program:** the folder's programs are ranked the way the folder import ranks them — the game over a launcher (a launcher you started on gives way to the game), installers and uninstallers never — and with more than one you can tap to choose.
- **A second copy of a game** is named "Name (2)", not after its .exe.

## 🧪 Stream games from network storage — experimental, work in progress

- **Add to Games › Stream from the network (test):** nothing is copied first; a placeholder of the game's folder is made in app storage, and each part of a file comes over from the drive the moment the game reads it. The drive must stay on and reachable while you play.
- **"Loading from NAS"** shows in the top right corner with how far along it is and how fast, while the game waits for files.
- **Keep on this device:** *Keep what's loaded* (the default), *Stream only* (emptied when the game closes) or *Keep a full copy*.
- **Streamed games** (a tile in the file manager's Network section): what each streamed game keeps, a size limit (5, 10, 20 or 50 GB, or none; over it, the games played longest ago are emptied first), **Free up space** and **Remove**.
- **Tried:** *Cyberpunk 2077* played from a NAS to its menu; *Darksiders Warmastered Edition* and *Streets of Rage Remake* start. Every read those games made was checked against the drive.
- **Still a work in progress:** some games have problems of their own on Bannerlator either way (the *GTA V* copy tested crashes while loading, and *Darksiders*' title video freezes, with a local copy too); a first start of a big game is slow while its data comes over; only a home network drive was tried.

## 🧪 Lab

- **Lab is a 1:1 equal of Classic:** every Classic option now has a Lab page, row or pop-up — settings, game actions and extras, containers, Contents, tools, the in-game menu and the theme — and Box64EC versions can be downloaded from Lab.
- **Touch:** every Lab page and pop-up has a back or close button you can tap, every button hint can be tapped, and full-screen Lab pages cover the whole screen.
- **Start page:** Settings › Open the app on — Home, Library or Containers.
- **Home:** the Library row starts at the game you played last.
- **Device details:** tap the device's name (the top line, or the drawer) for its chip, CPU, GPU, Vulkan driver, memory, Android and kernel details, with **Copy** for a bug report.
- **Library:** a thin outline round each game's card (covers, wide covers and icons).
- **Fixes:** the game-action and Add games buttons are drawn again; an imported .exe never writes over a game that is already there; restoring a save names the game; the file picker follows the app's Orientation; Save Manager's settings scroll in landscape.

## 🎮 XMB

- **Game Details › Add your own wide cover / Add your own background** (#671, **MGamer404**): Steam's art, SteamGridDB's, an image from the device, or automatic. They write the same slots as Lab's Wide cover and Background, so both looks show them.
- **The Home follows the Interface scale:** smaller settings shrink the covers, larger ones grow them, and the opened game view stays readable from 50 to 150 %. The tab labels keep their tuned size whatever Font size says.

## 🧱 Wayland

- **The Wayland desktop follows a game's display-mode change**, and windows are cut off at the edge of the Windows desktop: *Streets of Rage Remake* fills the screen with no strip of the console beside it.

## 🎯 Drivers

- **DroidDeck drivers:** a built-in **DroidDeck** source in the driver download lists (its DD-Turnip releases). A DD-Turnip zip holds an Android and a Linux driver: installing one asks which to add (Android ticked), Android goes to the Graphics Driver list and Linux to the Linux runtime drivers.
- **A Linux (glibc) driver can no longer land in the Android driver list.**

## 🛒 Stores

- **A close button in the store menu** that leaves the store.
- **Uninstall from a store's own page removes the game's shortcuts** (Steam, Xbox, Epic, GOG and Amazon), sharing the Download Manager's rules.

## 🔊 Menu sounds

- **The start-up sound comes only from the chosen sound pack**; every other sound a pack lacks still falls back to the Steam pack.

## ⚠️ Carried over — still open

- **Streaming from network storage** is experimental and a work in progress (see its section): some games don't run yet, big games start slowly the first time, and only a home network drive was tried.
- **Games:** the *GTA V* copy tested crashes while loading, and *Darksiders Warmastered Edition*'s title video freezes — both with a copy on the device too, so not streaming.
- **XMB art pickers:** the words inside the picker are English only for now.
- Everything listed as open in 3.2.0 is unchanged.
