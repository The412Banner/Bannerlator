# Bannerlator 3.2.2

Run Windows apps and games on Android — no PC and no root required.

<p align="center"><img src="https://img.shields.io/badge/release-3.2.2-ff3d8b?style=for-the-badge" alt="3.2.2" />&nbsp;<img src="https://img.shields.io/badge/update-app--side%20%C2%B7%20no%20ImageFS%20reinstall-2dd4bf?style=for-the-badge" alt="app-side update" />&nbsp;<img src="https://img.shields.io/badge/new-faster%20upscalers-22c55e?style=for-the-badge" alt="Faster upscalers" />&nbsp;<img src="https://img.shields.io/badge/new-frame%20gen%20engine%20in--game-22c55e?style=for-the-badge" alt="Frame gen engine switch in-game" />&nbsp;<img src="https://img.shields.io/badge/new-Wine%20%2F%20Proton%20list-22c55e?style=for-the-badge" alt="New Wine / Proton list" /></p>

**3.2.2 is everything since 3.2.1: faster upscalers (NIS about 5 times faster), switching the frame-gen engine while a game runs, a new Wine / Proton list with updates inside each Proton family, Sync CPU topology with core pickers that name each core, per-API idle-thread throttle switches, program cursors in Wayland desktop mode, community control profiles, Xbox Cloud Gaming sound on your TV or headphones, and store fixes from Winlator Ludashi and GameNative.**

- **Upscalers:** FSR, CAS and SGSR HQ + CAS use about a third less GPU time; NIS needs 80 % less, and a test game went from 186 to 246 fps with the same picture.
- **Frame generation in-game:** pick Off, LSFG Native, Win-FG Native or WFG while the game runs; in-game changes are kept for that game only.
- **Wine / Proton:** Proton and Wine tabs, grouped by family, one row per layer; GE-Proton 11.x containers are offered GE-Proton 11.0-14, Proton 11.0-2 is offered 11.0-3.
- **Cores:** Sync CPU topology tells a game how many cores it really has; core pickers, the HUD and the Task Manager name each core and dim the ones the game is not using.
- **Controls:** Community profiles list Winlator's original layouts and the layouts shared in our Discord.

# What's New — everything since 3.2.1

## 🔁 What changes when you update

- **In-game frame-gen changes are saved for the game**, not the container: a change made in one game no longer shows up in every game of that container, and opening the menu writes nothing.
- **Layer updates follow the Proton family:** a GE-Proton 11.0-9 container is now offered GE-Proton 11.0-14, Proton 11.0-2 is offered 11.0-3. Families never mix (GE, DroidDeck-Proton, CachyOS and Valve Proton stay apart).
- **Upscalers and CAS run in half precision by default**, on X11 and Wayland. CAS is AMD's default 5-tap filter.
- **Steam games Bannerlator starts itself** (Goldberg, raw and Headless Steam) get the arguments Steam gives them: *Counter-Strike* opens Counter-Strike instead of Half-Life.
- **The app data backup leaves out saved store logins.** After a restore, sign in to the stores again.
- **Removing a driver** resets only the games set to that driver.
- **AIO Graphics Test 2.3.1** (with Cursor Test) is in new containers and is updated in existing ones the first time they start.

## 🖥️ Upscalers

- **Faster:** measured on the Pocket FIT (AIO Graphics Test, DX11, X11 Vulkan renderer): FSR −29 % GPU time, CAS −37 %, SGSR HQ + CAS −35 %, SGSR −6 %, SGSR HQ −10 %.
- **NIS rewritten:** 3.41 → 0.67 ms a frame (−80 %); the test game went from 186 to 246 fps (263 without NIS). The picture matches the old NIS.
- **X11:** the cursor is drawn after the upscale at screen size, so it stays sharp; a frame where only the cursor moved redraws just that last step.

## 🎞️ Frame generation

- **Switch the engine while the game runs:** the in-game menu's Frame generation section has an engine picker (Off / LSFG Native / Win-FG Native / WFG) when the game runs through Bannerlator's renderer (X11 Vulkan renderer or Wayland). A game started with frame gen off can turn it on.
- **Per game:** multiplier, flow scale, model, preset, LSFG performance mode and capture resolution changed in-game stay with that game.

## ⚙️ Cores and performance

- **Sync CPU topology** (container and game, off by default): the game is told the cores it really runs on, from its final core pick. On the Elite, *DiRT Showdown* sees 6 processors instead of 8 and uses its 6-core worker setup.
- **Core pickers name each core:** grouped fastest first, as in "Prime · Cortex-X4 · 3.30 GHz", with All cores / Big cores (Lab, Classic and the in-game Task Manager).
- **Chip names:** Snapdragon G3 Gen 3, Dragonwing Q-7790 (was shown as Snapdragon 8 Elite), SM8750P, and Samsung's "for Galaxy" chips from the phone's own clocks.
- **HUD and Task Manager** dim the cores the game is not using; the in-game Performance page shows the game's cores.
- **Idle-thread throttle switches** (container and game, Classic and Lab): the v17 Wine layers slow down threads that spin with nothing to do. Very fast frame loops can be mistaken for idle ones (DirectDraw 2780 → 1460 fps on the Pocket FIT), so a switch per graphics API (DX7–DX12, OpenGL, Vulkan) chooses which games are never slowed. Default: DX7 games are never slowed.

## 🍷 Wine / Proton

- **One list, two tabs:** "Get Wine / Proton" and the container's "Wine / Proton version" are one dialog in Lab, Classic and the Deck look, with Proton and Wine tabs.
- **Grouped by family:** Proton (Valve), GE-Proton, DroidDeck-Proton, CachyOS and Other, newest first, one row per layer (its x86_64 build with the x86_64 switch), short names like "GE-Proton 11.0-14", and an Older builds section.

## 🧱 Wayland desktop mode

- **Program cursors:** the window under the pointer gets the cursor, so each program's own cursor shows (needs the v18 layers, see above).
- **Dragging:** a drag that leaves a program's window no longer makes the cursor flicker between the program and the desktop.
- **Older layers:** with v17 and older the pointer stays visible on program windows.

## 🎮 Controls and input

- **Community profiles:** an Original tab (Winlator's layouts by **brunodev85**) and a Discord shared tab (layouts from our Discord's #bannerlator-osc-sharing), with the author and a controller tag on each row; previews show each file's own icons.
- **Players › Bind controller profile:** sticks and the D-pad now work, not only the buttons.
- **Keys on on-screen sticks, D-pads and triggers** let go a little inside the dead zone, so a value resting on the edge does not press them over and over.
- **A keyboard that is also a pad:** its keyboard keys reach the game.
- **A captured external mouse** works while the on-screen controls, a menu or the keyboard has focus.
- **Xiaomi's uinput device** is no longer taken for a controller.

## 🛒 Stores

- **Steam:** games that take depots from another app install complete (*Counter-Strike 1.6* and Half-Life); Real Steam and SteamLite launches get the shortcut's launch arguments; Bannerlator records the source app (Half-Life for Counter-Strike) so SteamLite launches stay secure (VAC); QR sign-in takes the account id from the message header when the logon reply has none; the SteamLite report reads both the start and the end of a long Wine log.
- **GOG:** installs and update checks use the game's default branch, not a public beta; Verify and Update keep the files an installed DLC replaces; uninstalling a game forgets its DLC too; the game page no longer stays on "Verifying files…" or "Updating…".
- **Epic:** DLC installs into its game's folder, and uninstalling forgets it.
- **Downloads:** a "Download complete" notification when a download finishes.

## ☁️ Xbox Cloud Gaming

- **Sound plays as game audio in stereo** and follows HDMI, USB and Bluetooth output. It used to be treated as a voice call and stayed on the device's speaker.

## 🧰 Also

- **Frontend shortcuts** (ES-DE and others) keep their container, and closing a game a frontend started returns to the frontend.
- **Folders picked through Android's Downloads entry** get their real path.
- **Lab notes** no longer repeat their title under the heading.

## ⚠️ Carried over — still open

- **Program cursors in Wayland desktop mode** need the v18 Wine / Proton layers (see above); with older layers the pointer keeps one shape per window and edge-drag resize does not work.
- **Streaming from network storage** is still experimental and a work in progress.
- **Games:** the *GTA V* copy tested crashes while loading, and *Darksiders Warmastered Edition*'s title video freezes.
- **XMB art pickers:** the words inside the picker are English only for now.
- Everything listed as open in 3.2.1 is unchanged.
